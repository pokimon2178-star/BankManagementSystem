# Bank System (Golang Edition) 🚀

Простая консольная система управления банковскими счетами, переписанная с **C#** на **Go**. Этот проект наглядно показывает различия между объектно-ориентированным подходом (ООП) и структурным подходом в Golang.



## 📁 Структура проекта

Код разделен на логические модули для удобства навигации и поддержки:

* **`client.go`** — описание структуры `Client` (аналог класса в C#), хранение персональных данных и валидация возраста.
* **`bank.go`** — бизнес-логика: регистрация, управление списком клиентов, система безопасности (блокировка при неверном пароле) и создание счетов.
* **`main.go`** — точка входа в приложение. Содержит главный цикл управления и консольный интерфейс для пользователя.
* **`go.mod`** — файл инициализации модуля, позволяющий запускать проект как единое целое.

## 🛠 Функционал

Приложение имитирует работу реального банка:
1.  **Регистрация**: Создание профиля клиента с проверкой возраста (18+).
2.  **Безопасность**: Аутентификация по паролю (по умолчанию `1234`). Система автоматически блокирует доступ после **3-х неудачных попыток**.
3.  **Управление счетами**: Генерация уникальных номеров счетов вида `ACC-XXX`.
4.  **Мониторинг**: Проверка транзакций на подозрительно высокие суммы (более 100,000).

## 🚀 Как запустить у себя

1.  Убедитесь, что у вас установлен [Go](https://go.dev/dl/) версии 1.18 или выше.
2.  Склонируйте репозиторий или скачайте файлы в рабочую папку.
3.  Откройте терминал в папке проекта.
4.  Запустите приложение командой:
    ```bash
    go run .
    ```

## 💡 Чему я научился при переходе с C# на Go
* **Композиция вместо наследования**: Использование структур (`struct`) и методов.
* **Обработка ошибок**: Переход от `try-catch` к явной проверке ошибок (`if err != nil`).
* **Управление пакетами**: Работа с Go Modules для связи нескольких файлов в одном `package main`.
