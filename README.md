# Bank Management System v3.0

Простая консольная имитация банковской системы на C#, демонстрирующая базовые принципы ООП, работу со списками и обработку исключений.

## 🚀 Функционал
* **Регистрация клиентов**: Проверка возраста (18+) и автоматическая генерация уникального ID (Guid).
* **Безопасность**: Система аутентификации с ограничением попыток ввода пароля (блокировка после 3 ошибок).
* **Управление счетами**: Возможность открытия нескольких расчетных счетов для одного клиента.
* **Мониторинг транзакций**: Автоматическая проверка операций на подозрительно высокие суммы.
* **Уведомления**: Имитация рассылки с учетом "тихого режима" в ночное время.

## 📂 Структура проекта
После рефакторинга проект разделен на логические модули:
* `Client.cs` — Модель данных клиента и валидация при создании.
* `Bank.cs` — Бизнес-логика: управление списком клиентов, счета, безопасность.
* `Program.cs` — Пользовательский интерфейс и главный цикл обработки команд.
